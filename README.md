# Recipe and Cooking Platform

Recipe and Cooking Platform where users can create profiles, manage recipes, discover public recipes, cook with timers, save favorites, join cooking challenges, earn points and badges, and connect with other users through social features.

---

## Project Overview

This project is designed to make cooking more personal, social, and engaging. Users can upload their own recipes, receive personalized recipe recommendations, track cooking progress, join challenges, and interact with other users in the community.

The platform combines recipe management, personalized nutrition preferences, progress rewards, and community features in one system.

---

## Key Features

###  Profile & Cooking Preferences

- Users can create and edit their profile.
- Profile includes:
  - Name
  - Date of Birth
  - Gender
  - City
  - Dietary preferences
- Users can set personal cooking and nutrition goals.
- Users can specify:
  - Dietary restrictions
  - Favorite cuisines
  - Cooking preferences

---

###  Add New Recipe

Users can upload their own recipes with:

- Recipe title
- Ingredients
- Cooking steps
- Cooking time
- Difficulty level
- Cooking tips
- Author information

---

###  Recipe Trash 

The Recipe Trash shows deleted recipes with full details, including:

- Full recipe information
- Ingredients
- Cooking steps
- Author name

---

## Recipe Management

### Personalized Recipes

The system recommends recipes or meals based on:

- Dietary preferences
- Nutritional goals
- Favorite cuisines
- Dietary restrictions

---

### AI Cooking Chatbot

The platform includes an AI chatbot that can help users with:

- Cooking tips
- Recipe suggestions
- Ingredient alternatives
- Step-by-step cooking guidance

---

### Personalized Recipe Ideas

The system provides recipe ideas based on user preferences, such as:

- Age
- Dietary preferences
- Nutritional goals
- Dietary restrictions

---

### Recipe Search

Users can search recipes by:

- Recipe title
- Ingredient name

Search works in:

- User’s own recipes
- Public recipe page

---

### Cooking Mode with Timer

Users can select any public recipe to cook.  
When cooking starts, a timer appears to track the cooking progress.

---

### Favorite / Save Recipes

Users can save recipes from the public feed to their personal Favorites list.

Users can also remove saved recipes later.

---

## Progress Tracking & Gamification

### Cooking Activity Tracker

The system tracks:

- Recipes cooked
- Cooking date
- Review history

---

### Cooking Challenges

Users can participate in different cooking challenges to improve their cooking habits and skills.

---

### Achievement Badges

Users can unlock badges by completing cooking challenges and reaching milestones.

- First Recipe Added
- First Recipe Cooked
- Challenge Completed

---

### Points System

Users can earn points by:

- Adding new recipes

- Completing challenges
- Interacting with the community

---

### Progress Dashboard

The dashboard shows:

- Total points
- Earned badges
- Number of recipes cooked
- Challenge progress
- Cooking activity summary

### Public Recipe Feed
